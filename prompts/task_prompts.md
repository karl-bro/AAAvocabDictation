# 任务级提示词模板（User Prompt）

> 与 `system_prompt.md` 配套：系统提示定义「怎么调用」，这里的模板定义「一次具体任务怎么发起」。
> 每个模板都可以原样粘给应用里的对话框，只替换 `{}` 占位内容。
> 每个模板后面标了**期望动作序列**，方便你在自己的应用里做断言或写回归测试。

---

## 模板 1 · 首次使用：建库 + 今日入库

```
（附生词本照片，可多页）

新建词库并识别这两页生词：{词库路径}。
先只回核对清单（序号/类型/英文/词性/中文/标记/等号链/备注），
把我写的字迹不确定的地方标出来；我确认后你再入库，不要自己先写库。
```

期望序列：`bank.stats`（探测）→ 报不存在 → `bank.init`（用户同意后）→ 识别 → **停**（核对清单）→ 用户确认 → `bank.add_items(source="{页眉}-p1", date="{今天}")`。

要点：
- 不确认就 `bank.init` 属于越权；已有词库时更不能 `overwrite`。
- 入库时 `source` 用页眉编号+页码，不要用「今天」「第一页」这种自然语言。

---

## 模板 2 · 全量打乱出卷（最常用）

```
把这两页（{页眉} p1~p2）的全部词汇打乱顺序出卷，不用从词库中补题，也不要错题优先。
出卷后只发填空版给我，答案版你自己留着。
```

期望序列：`dictation.batch_id(date=今天)` → `dictation.shuffle_all(scope={"来源":["{页眉}-p1","{页眉}-p2"]}, seed=任意)` → `dictation.build_pdf(items, meta={批次ID,日期,范围}, outdir)` → `verify == "OK"` → **只交付填空版**。

要点：
- 「全部词汇打乱」对应 `shuffle_all`，不是 `sample(n=全部数量)`：后者会走错题优先与分层抽样，题量够时也可能漏词。
- 出卷题量必须等于范围内词条数；`shuffle_all` 不补题，天然满足。

## 模板 3 · 抽 N 题（当天页 / 指定区间 / 只听主词）

```
从今天的 {页眉}-p1 里抽 {N} 题，优先出我没记住的（错题优先）。
```

```
从今天这两页里抽 {N} 题，只要 {序号区间} 号之间的词。
```

```
从今天页里抽 {N} 题，只听主词，词组不要。
```

期望序列：`dictation.batch_id` → `dictation.sample(n=N, scope={...}, wrong_ratio=0.6)` → `dictation.build_pdf` → 交付填空版。

要点：
- 没给范围时才默认「今天上传的页」；一旦用户说「从词库抽查 / 综合复习」，才把 `scope` 省略或放大到全库。
- `scope` 的键是中文：`来源`、`类型`、`标记`、`序号区间`、`序号集合`。

## 模板 4 · 批改 + 报告

```
（附答卷照片）

批改这份完成稿。先逐字转写我的答案给我看一眼再判分，别替我改拼写；
判完先给我预览，我确认后你再写库、出报告。
```

期望序列：`submission.prepare`（可选，装 `[image]` 时）→ 读图逐字转写 → `grading.preview(batch_id, graded=[{词条ID,我的答案}])` → **停** → 用户确认 → `grading.apply(...)` → `report.build(result, out)` → 交付报告 + 复述得分/正确率/错题/抄默清单。

要点：
- `graded` 的顺序就是题号顺序，`词条ID` 取自出卷时 `items[i].词条ID`，不要按英文重新查库。
- 同一 `batch_id` 二次 `apply` 会报 `DUPLICATE_BATCH`；这是护栏，不是 bug。

## 模板 5 · 词库维护与复盘

```
把 {词条ID}（{英文}）的中文释义改成「{新释义}」，等号链标「是」，和其他链成员对齐。
```

```
看一下我现在的词库状态：总共有多少词、多少还在学习中、最近一次听写是什么时候。
```

```
把 {词条ID} 的标记从「普通」改成「重点词」，只改这一条，别动统计列。
```

期望序列：`bank.list_items(query=...)` 定位 → `bank.update_item(item_id, fields={...})` → 回报 changed 字段；复盘用 `bank.stats` + `bank.list_items(status="学习中")`。

要点：
- 改词条只动被点名的字段，统计列（听写次数/连续正确）由 `grading.apply` 维护，手工改会污染历史。
- 若用户说「和其他链成员对齐」，先 `bank.list_items(query=链成员中文)` 查清有哪些成员，再逐条改并在回复里列出。

## 组合用法：一句话触发整条链路

```
今天的听写我全流程走一遍：{页眉} 这两页，全部打乱出卷，我做完拍照给你。
```

模型应理解为：识别 → 核对（**停**）→ 入库 → 取批次号 → `shuffle_all` → 出卷（交付填空版）→ 等答卷。
即使一句话要求「全流程」，**核对与批改确认两个停点依然保留**——这是数据安全边界，不是啰嗦。
