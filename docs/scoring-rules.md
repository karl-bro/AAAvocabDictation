# 评分口径（唯一权威）

本文件与 `src/vocab_dictation/core.py::judge` 一一对应。改口径必须同时改代码与本文，
并用 `tests/test_judge.py` 锁住边界。

## 三档评分

| 情形 | 得分 | `错误类型` |
| --- | --- | --- |
| 拼写完全正确；斜杠同义词写出任一支 | **1** | `""` |
| 单词错 1~2 个字母且整体可辨认；3~4 字母短词只容错 1 个 | **0.5** | `拼写错误` |
| 拼写偏差大、无法辨认 | **0** | `完全不会` |
| 未作答 / 全空白 | **0** | `未作答` |
| 词组漏词 | **0** | `词组漏词` |
| 词组多词、单词拼错 | **0** | `词组错误` |
| 词组单词全对但顺序错 | **0** | `词序错误` |

关键约定：

- **半对也算一次错误**：`0.5` 会清零 `连续正确`、写入错题本、计入 `错题数`。
- 正确率有两个口径，报告里都要区分：
  - `正确率` = 满分题数 / 题数（与历史报表一致）；
  - `平均得分率` = 总分 / 题数（把 0.5 折算进去）。
- 重点词与熟词僻义单独统计 `重点正确数 / 重点题数`。

## 文本归一化（判分前统一执行）

1. 小写；
2. 去标点：`.,，。；;：:!！?？（）()[]【】"'’‘…~～=`；
3. 连字符 `-`、斜杠 `/`、全角斜杠 `／` 转为空格；
4. 压缩连续空白。

因此 `Self-Deception!` 与 `self deception` 等价，`lay off.` 与 `lay off` 等价。
**冠词、介词不会被忽略**：`a pink slip` ≠ `pink slip`（多词 → 词组错误）。

## 斜杠同义词展开

`expand_slash("optional/selective course")` → `["optional course", "selective course"]`；
`maintain/hold/believe that` → 三个完整短语。写出任一支即满分。

## 分支顺序（决定错误类型，务必不要调换）

1. 空白 → 未作答（0）
2. 判定是否词组：`类型 == 词组` **或** 任一支答案含空格
3. 词组分支：完全相等 → 1；词集相同但顺序不同 → 词序错误；有缺词 → 词组漏词；
   其余 → 词组错误
4. 单词分支：命中任一支（含“斜杠拼接”写法）或词集相同 → 1；
   `距离 ≤ 2` 且 `长度 ≥ 5` → 0.5；`距离 = 1` 且 `3 ≤ 长度 < 5` → 0.5；
   其余 → 完全不会

> 由于 0.5 的容错窗口（≤2 字母）总是先命中，`拼写错误` 实际只会以 0.5 出现；
> 偏差更大的答案统一归为 `完全不会`。这是刻意的：错误类型要能指导复习动作，
> “拼错一点”和“根本没记住”的处理方式不同。

## 摘帽（错题本生命周期）

```
首次错 → 错题本状态=待复习，连续正确=0
再答对（1 分）→ 连续正确=1，状态仍待复习
再答对（1 分）→ 连续正确=2 → 总词库状态=已掌握，错题本状态=已摘帽，写摘帽日期
期间任何一次 <1 分 → 连续正确清零，重新累计
```

## 出卷时的错题优先

`dictation.sample` 中错题最多占 `ceil(n * wrong_ratio)`（默认 0.6），
其余按分层随机：未听写的熟僻/重点 → 未听写普通 → 学习中 → 已掌握。
`dictation.shuffle_all` **不做**错题优先，也不从词库补题——它就是“范围内全量打乱”。
